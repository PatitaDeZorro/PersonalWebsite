# Cómo agregar contenido editable El sitio mantiene sus secciones repetibles en archivos JSON para que puedan crecer sin duplicar bloques HTML. ## Portafolio La sección de portafolio se genera desde: `assets/data/portfolio.json` Para agregar un nuevo proyecto: 1. Copia las imágenes del proyecto dentro de `assets/img/portfolio/`. 2. Abre `assets/data/portfolio.json`. 3. Duplica un objeto existente. 4. Cambia estos campos: - `id`: identificador único del modal, por ejemplo `portfolio-memory-game-modal`. - `category`: categoría usada por los filtros. - `app`: Web - `product`: Datos - `branding`: Consultoría - `books`: Documentos - `image`: imagen principal de la tarjeta. - `gallery`: imágenes del modal. - `badges`: tecnologías o etiquetas del proyecto. - `link`: enlace del botón principal. - `content.es`: textos en español. - `content.en`: textos en inglés. No es necesario editar `index.html`, `assets/i18n/es.json`, `assets/i18n/en.json` ni `assets/js/modals.js` para agregar proyectos de portafolio. ## Servicios La sección de servicios se genera desde: `assets/data/services.json` Para agregar un servicio: 1. Duplica un objeto existente. 2. Cambia `id`, `icon`, `badges` y los textos dentro de `content.es` y `content.en`. 3. Usa un icono de Bootstrap Icons en `icon`, por ejemplo `bi-window-sidebar`. El modal del servicio se crea automáticamente desde el mismo objeto. ## Trayectoria académica La sección de trayectoria se genera desde: `assets/data/resume.json` Para agregar formación académica: 1. Agrega un objeto en la columna `academic`. 2. Define `logo`, `fallback` y los textos en `content.es` y `content.en`. Para agregar educación continua: 1. Agrega un objeto en la columna `continuing`. 2. Define el título y la lista de enlaces en `links`. GitHub Pages puede publicar esta estructura sin backend porque todo se carga como archivos estáticos: HTML, CSS, JS, JSON e imágenes.
